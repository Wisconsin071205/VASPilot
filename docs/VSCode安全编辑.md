# VS Code 安全编辑远端文件

“远端控制智能体 VS Code Bridge”让一个最新版 VS Code 按需打开远端计算目录中的文本文件。它不会通过 Remote-SSH 登录 `cl12`、`minus` 等老集群，因此不会向这些服务器安装 VS Code Server，也不受 CentOS 7 的 glibc 限制。

## 一次安装

1. 启动「远端控制智能体」并完成目标服务器连接（服务器可选择 Vlab 中转或本机直连）。
2. 在 Windows 上安装最新版 VS Code。
3. 运行 [install-windows.ps1](../apps/huwei-agent-vscode-bridge/install-windows.ps1)。脚本会安装仓库内的 `.vsix` 扩展包。
4. 重启 VS Code 一次；扩展会出现在扩展列表中，名称为“远端控制智能体 VS Code Bridge”。

每一台新电脑都需重复以上安装；使用 Vlab 中转时配置该电脑自己的 Vlab PEM，使用直连时确保本机能访问目标服务器。直连可在服务器编辑窗口选择将密码和 Google Authenticator 的 TOTP 种子用 Windows DPAPI（CurrentUser）加密保存，自动连接时仅短暂注入本机 SSH 子进程；默认每 3 天需要点击一次「确认凭据」，确认前不使用已保存凭据。也可以继续使用 SSH 密钥/代理或独立终端手工登录。不共享私钥、本机绝对路径或凭据内容。

## 打开和保存

1. 在智能体的“文件”页进入已连接服务器的计算目录。
2. 右击普通文件，选择“在 VS Code 中安全编辑”。
3. 右击文件夹，选择“在 VS Code 中以虚拟目录打开”。
4. 在 VS Code 中修改后按 `Ctrl+S` 保存。

读取、展开目录和保存均经过本机控制台的受限文件助手，再按服务器配置经 Vlab 或 SSH 直连到目标服务器。打开目录只列出当前目录的直接子项；不会递归扫描服务器。

保存时，智能体会比较打开文件时记录的 SHA-256：

- 未变化：内容先写入同目录临时文件，校验成功后原子替换目标文件。
- 已变化：保存被拒绝，远端原文件不变；请重新载入并比较后再决定如何处理。
- 删除：进入远端智能体回收站，而不是永久删除。

## 保护范围和限制

- 单目录默认只显示前 500 项；达到上限时 VS Code 会提示缩小路径或使用受限远端搜索。
- 在 VS Code 命令面板运行“远端控制智能体：在远端路径中搜索”，只会搜索当前虚拟目录的两层内容，最多返回 200 项。
- 只允许打开不超过 32 MiB 的 UTF-8 文本。
- `WAVECAR`、`CHGCAR`、`AECCAR0`、`AECCAR2` 及网关拒绝的其他 VASP 二进制数据不能作为文本编辑。
- 若控制台未启动、服务器未连接，或所选链路会话过期，扩展会提示重新启动控制台或重新连接服务器。
- 当前阶段不支持在虚拟目录中重命名或移动文件；请在智能体文件页或集群终端执行这些操作。

## 常见问题

**浏览器提示没有应用可打开 VS Code 链接**

确认已运行安装脚本，并从 VS Code 扩展页确认 Bridge 已启用。然后刷新智能体文件页并再次右击打开。

**提示“本地控制台未运行或无法访问”**

启动“远端控制智能体”控制台。扩展通过 `%USERPROFILE%\.rsci\ui.json` 自动发现本机控制台地址和临时令牌。

**提示“远端文件已被其他操作修改”**

这是冲突保护。远端版本被保留；请关闭未保存的编辑、重新打开文件，比较差异后再修改。
