模型服务

        
每个服务商有自己的 API 地址（可含端口）和密钥。密钥以
          Windows 凭据加密保存在本机（不明文落盘），保存后即可直接对话；切换模型用左侧下拉框。

        

        

          
          
          
        

      


      
      

        
连接设置

        

          

            Vlab PEM 私钥路径
            
SSH 连接 Vlab 计算集群（vlab.ustc.edu.cn）用

          

          
        

        

          

          

          

          

        

        

        

        

          

            远端服务器
            
在左侧「服务器」面板添加与连接；密码与六位验证码只在连接时于独立 SSH 窗口输入，凭据不会保存在任何地方。

          

        

      


      
      

        
智能体执行策略

        
控制智能体（大模型）提交作业前是否需要人工确认。本地与远端 shell 命令始终开放且仅全量审计（命令、退出码、输出全部留痕）。

        

          

            提交作业确认
            

          

          

            
            
          

        

      


      
      

        
联网搜索

        
允许智能体搜索文献值、数据库参考与报错解法。API Key 用 Windows 凭据加密保存（界面不回显）。关闭后 web_search 工具不可用。

        

          

            

              

            

              

          

          

            
            
            
            
          

        

      


      
      

        
技能（智能体的可进化知识）

        
技能是一段可复用的操作指南，会注入到智能体的系统提示中。智能体可用 skill_write 自建技能（自进化）；删除与重写由你在本页管理。

        

        

          
          
        

      


      
      

        
监测

        
「监测」板块只做观测，与智能体计算任务完全分开：智能体不能看到本页的任何
          历史/用量数据，它依旧通过自己的只读工具在提交前查询实时资源。

        

          

            

              

            
          

          

            掉线提醒在状态翻转时提示一次；超温提醒对每台服务器有 10 分钟冷却期。
          

        

        
离线采集守护（可选）
          

            在远端 ~/.vp-monitor/ 放置一个每分钟自采的小循环：
            只在你离开页面（心跳静默 >90 秒）时补采 CPU/内存/GPU 占用与按用户的 GPU 使用快照，
            断线期间热力图与使用分布不再出现空洞。卸载时脚本与数据一并移入远端回收站。
          

      


      
      

        
关于 VASPilot

        

          

            VASPilot 
          

          

            
工具面命名工具注册表 + 本地/远端 shell（仅全量审计，无拦截）

            
调度器状态 ≠ 科学收敛两者的判定与展示始终分离

            
提交作业默认聊天卡片人工确认；可在「智能体」页切换全自动

            
POTCAR / 密钥正文与密钥绝不明文落盘；POTCAR 只以元数据示人

            
审计日志~/.vaspilot/audit/（追加式、自动脱敏；shell 命令全量留痕）

            
命令行vaspilot --help
