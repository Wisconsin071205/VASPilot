# 本机服务器凭据要求

## 功能范围

1. 仅直连目标服务器允许保存登录密码和 Google Authenticator 的 TOTP 种子。
2. TOTP 输入必须是 Base32 密钥或 `otpauth://` URI，不接受并保存一次性六位验证码。
3. 凭据写入前必须使用 Windows DPAPI `CurrentUser` 加密；JSON、计划、日志、
   聊天记录和 MCP 输出只能出现状态字段，不能出现明文。
4. 自动连接时通过短生命周期 `SSH_ASKPASS` 子进程回答 SSH 密码/验证码提示，
   凭据不得进入命令行参数。

## 周期确认

1. 默认保存周期为 3 天，可按服务器设置为 1–30 天。
2. 到期后不解密、不使用已保存凭据；Web 控制台显示「确认凭据」操作。
3. 只有用户明确点击确认后才刷新 `confirmed_at` 并恢复自动连接。
4. 删除服务器或切换回 Vlab 时删除直连凭据条目；DPAPI 无法解密时要求重新录入。

## 失败与兼容

- 未保存凭据、确认已到期、服务器拒绝密码/键盘交互认证时，返回
  `auth_required` 并保留可见终端登录方式。
- SSH 主机密钥仍然严格校验，应用不得自动修改 `known_hosts`。
- Vlab 中转不接收或转存目标服务器密码/TOTP；Vlab 路由继续使用原有可见终端或
  SSH 密钥流程。
