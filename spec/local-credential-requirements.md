# 本机服务器凭据要求

## 功能范围

1. Vlab 中转和直连目标服务器都允许在 Windows 本机保存登录密码和 Google
   Authenticator 的 TOTP 种子。
2. TOTP 输入必须是 Base32 密钥或 `otpauth://` URI，不接受并保存一次性六位验证码。
3. 凭据写入前必须使用 Windows DPAPI `CurrentUser` 加密；JSON、计划、日志、
   聊天记录和 MCP 输出只能出现状态字段，不能出现明文。
4. 直连自动连接通过短生命周期 `SSH_ASKPASS` 子进程回答 SSH 密码/验证码提示，
   凭据不得进入命令行参数。
5. Vlab 中转自动连接只通过已验证的外层 SSH 通道标准输入发送密码和当期六位
   TOTP；TOTP 种子不得离开本机，密码和验证码不得在 Vlab 写入文件、配置或日志。

## 周期确认

1. 默认保存周期为 3 天，可按服务器设置为 1–30 天。
2. 到期后不解密、不使用已保存凭据；Web 控制台显示「确认凭据」操作。
3. 只有用户明确点击确认后才刷新 `confirmed_at` 并恢复自动连接。
4. 删除服务器时删除对应凭据条目；切换 Vlab/直连路由时可保留同一目标服务器
   的凭据。DPAPI 无法解密时要求重新录入。

## 失败与兼容

- 未保存凭据、确认已到期、服务器拒绝密码/键盘交互认证时，返回
  `auth_required` 并保留可见终端登录方式。
- SSH 主机密钥仍然严格校验，应用不得自动修改 `known_hosts`。
- Vlab 中转仅在一次连接进程的内存中接收密码和当期 TOTP，不接收 TOTP 种子，
  不转存任何凭据；没有有效本机授权时继续使用可见终端或 SSH 密钥流程。
